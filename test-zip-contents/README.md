# Test Project

This is a test project for testing the zip file upload functionality.

## Files Included:
- `package.json` - Node.js project configuration
- `index.js` - JavaScript file with embedded SQLite database code
- `test.db` - SQLite database file
- `.env` - Environment configuration with database connection
- `database.json` - Database configuration file

## Database Content:
- SQLite database with users table
- Configuration files for database connections
- Source code with embedded database operations
