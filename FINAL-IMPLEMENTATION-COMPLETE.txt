NEW ADAPTERS IMPLEMENTED IN THIS SESSION:
================================================================================

LARAVEL ADAPTER (laravelAdapter.ts):
  - Parses Schema::create() and Schema::table() migration methods
  - Extracts Blueprint column definitions ($table->string(), $table->integer())
  - Handles all Laravel column types and modifiers
  - Extracts indexes, unique constraints, and foreign keys
  - Parses ->nullable(), ->unique(), ->default() modifiers
  - Maps Laravel types to SQL types (VARCHAR, INTEGER, BIGINT, etc.)

ELOQUENT ADAPTER (eloquentAdapter.ts):
  - Parses Eloquent Model classes extending Model
  - Extracts $fillable array for field definitions
  - Infers types from $casts property mappings
  - Auto-adds id field and timestamps (created_at, updated_at)
  - Implements Laravel table naming conventions (pluralization)
  - Converts Model properties to database schema

HIBERNATE ADAPTER (hibernateAdapter.ts):
  - Parses @Entity annotated Java classes
  - Extracts @Table annotation for table names
  - Parses @Column annotations with nullable, unique flags
  - Handles @Id and @GeneratedValue for primary keys
  - Extracts @ManyToOne, @OneToOne relationships
  - Parses @JoinColumn for foreign key definitions
  - Maps all Java types to SQL types (including LocalDate, UUID, etc.)

JPA ADAPTER (jpaAdapter.ts):
  - Full JPA annotation support (@Entity, @Table, @Column)
  - Parses @Id, @GeneratedValue with strategy support
  - Extracts table-level @Index annotations
  - Handles schema attribute in @Table
  - Parses @JoinColumn for relationship mapping
  - Supports all JPA temporal types and UUID
  - Maps GenerationType strategies (AUTO, IDENTITY, SEQUENCE, TABLE)

SPRING DATA ADAPTER (springDataAdapter.ts):
  - Parses Spring Data @Entity classes
  - Extracts JpaRepository interface definitions
  - Infers entity relationships from repository definitions
  - Full JPA annotation support (same as JPA adapter)
  - Tags entities with spring-boot metadata
  - Repository pattern recognition

ALEMBIC ADAPTER (alembicAdapter.ts):
  - Parses op.create_table() migration operations
  - Extracts sa.Column() definitions from migrations
  - Handles all SQLAlchemy column types
  - Parses nullable, primary_key, unique, autoincrement flags
  - Extracts sa.ForeignKeyConstraint definitions
  - Maps Alembic/SQLAlchemy types to SQL types
  - Handles server_default and default values
